# Next.js + Vercel Starter

A clean, responsive Next.js starter that is ready for GitHub and Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Main files to edit

- `app/page.tsx` — your content and page structure
- `app/globals.css` — colors, spacing, typography, layout
- `app/layout.tsx` — site title and metadata

## Deploy

Push this folder to GitHub, then import the repository into Vercel.
Vercel automatically detects Next.js and uses the standard build settings.

## Free URL

A Vercel deployment includes a free `*.vercel.app` URL.
Example: `https://your-project.vercel.app`

A custom domain such as `yourname.com` is normally not free because the domain itself must be registered.
